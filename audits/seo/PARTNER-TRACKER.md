# PARTNER-TRACKER — Phase 5.5 partner backlink program

*Created: 2026-05-13. Source list: `audits/seo/PARTNER-PROSPECTS.md`. Outreach templates: `audits/seo/PARTNER-OUTREACH-TEMPLATES.md`.*

Update this file the same day an outreach is sent. The point of the tracker is honest accounting — pitched vs. heard back vs. landed.

## Column key

- **#** — order matches the prospect list
- **partner-name** — display name
- **category** — A sanctuary · B fund · C school · D network · E publication · F AI-citation
- **tier** — T1 if FRQNCY already covers them (existing page on /places, /orgs, /people, /media); T2 otherwise
- **contact-channel** — email or web form used for the first touch
- **pitched-on** — YYYY-MM-DD when the first outreach went out
- **status** — `not-yet-contacted` / `pitched` / `replied-warm` / `replied-cold` / `passed` / `accepted` / `link-landed`
- **last-touch** — YYYY-MM-DD of the most recent communication in either direction
- **reciprocal-link-confirmed** — `no` / `yes` / a URL
- **notes** — brief, factual

## Top-of-funnel discipline

- The tracker is the truth. If a send isn't logged here, it didn't happen.
- Cap sends to 5 per day. Volume kills tone.
- Tier-1 first. Existing pages give Orlando legitimacy in the opening line.
- 30-day rule: if no reply, one polite follow-up. After that, leave it for 90 days.
- When a reciprocal link lands, paste the URL into `reciprocal-link-confirmed` and verify at 30 / 60 / 90 days.
