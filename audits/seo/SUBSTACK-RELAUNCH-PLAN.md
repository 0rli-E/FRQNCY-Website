## C · Migration considerations

Substack's product reality (verified 2026-05-14): a publication owner can change the publication name, subtitle, about-page copy, topic mix, cover image, recommendations, sections, and welcome email at any time, with no effect on the existing subscriber list or the URL. The `frqncy.substack.com` slug is stable. RSS continues. Existing subscribers (if any — list size unverified from outside; Orlando should check the admin) receive the next post under the new name.

### Migration steps in execution order

1. **Audit subscriber list** (5 min) — log into the Substack admin, note current subscriber count + most-recent-active count + any auto-imports from `frqncy.network/newsletter` (likely zero — the newsletter backend is not yet wired). This is the baseline.
2. **Pause the old archive's visibility** (2 min) — Substack does not have a "hide all old posts" toggle, but you can move the entire 2023 archive to a new section called "Pre-relaunch archive" and leave it un-pinned. Old posts stay readable for honesty; they no longer dominate the front grid.
3. **Update publication metadata** (10 min) — name, subtitle, about, cover image, byline, topics, sections. Save.
4. **Update the welcome email** (5 min) — paste the new welcome (drafted as Issue 1's opening). New subscribers receive this immediately.
5. **Set up recommendations** (15 min) — recommend the 6-8 highest-overlap newsletters from `NEWSLETTER-PROSPECTS.md` (one-direction action; their consent not required). This is the only growth lever Substack provides that compounds without spend.
6. **Update the X bio links + the homepage `Organization` sameAs** (5 min, outside Substack) — `@0xOrli`'s link in bio moves from `frqncy.substack.com` to `frqncy.network/people/orlando/` per `SAMEAS-MATRIX.md` §2. The homepage Organization JSON-LD already includes the Substack URL in its sameAs array (per the v1.5 array in `SAMEAS-MATRIX.md`); leave that intact.
7. **Ship Issue 1 — the relaunch announcement** (per §G below). This is the subscriber-facing communication that the publication has moved.
8. **Wait 7 days. Watch the unsubscribe rate.** The reposition will cost a fraction of the 2023 crypto-era list — anywhere from 5% to 40% depending on how many of them actually wanted crypto updates. That is the price and it is worth paying. The remaining list is the seed of an editorial readership.
9. **Ship Issue 2 — the first long-form cross-publish** (per §G).

### Subscriber-communication note

Issue 1 *is* the communication. There is no separate "we're relaunching" email. The first issue does that work explicitly: it names the old publication, names what is changing, names what stays the same, and invites unsubscribe-without-judgment for anyone who joined for crypto and doesn't want consciousness. No defensiveness. Voice rule: state the change, don't over-explain.

## D · Custom-domain decision

**Verified 2026-05-14 against Substack's current pricing:** custom-domain support is a **one-time $50 USD fee per publication**, not a recurring monthly cost. (The prompt referenced $80-100/mo — that was Substack Pro's old positioning and is incorrect for 2026.) After paying the fee, custom domains can be added/swapped without extra charge. Free-tier publications keep all other features; the platform only takes a cut (10%) of *paid* subscription revenue.

This re-frames the decision. The trade-off is not "free vs. $100/mo," it is "free `frqncy.substack.com` vs. $50-once `essays.frqncy.network`."

### Recommendation: **defer the custom domain until Issue 4 has shipped.**

Reasoning, in order:

1. **No SEO penalty for staying on `frqncy.substack.com` initially.** Substack-subdomain URLs are well-indexed; the `mainEntityOfPage` schema points wherever you say it points; backlinks accrue to whatever URL is canonical.
2. **A custom-domain move *is* a URL change.** Substack handles the 301 redirects from `frqncy.substack.com/p/<slug>` to `essays.frqncy.network/p/<slug>` cleanly, but every redirect costs a few percent of link equity until Google re-resolves the canonical. Doing it after four shipped issues — when there is something to redirect — is more honest than doing it on day zero with no live content.
3. **`$50 once` is below decision-paralysis cost.** This is not a budget question; it is a sequencing question. Pay it once Orlando has decided which subdomain to use.
4. **The recommended subdomain is `essays.frqncy.network`** rather than `newsletter.frqncy.network` or `frqncy.network/newsletter`. Reasons:
   - The `/newsletter/` route on `frqncy.network` is already shipped as a UI surface (per `VISIBILITY-PLAN.md`); it should remain the *signup form* surface, not the *content* surface. Two distinct affordances on two distinct URLs.
   - `essays.frqncy.network` names what is there. `newsletter.frqncy.network` names a delivery mechanism.
   - Subdomain not subdirectory: Substack only supports subdomains for custom-domain mode, not subpaths. (`frqncy.network/newsletter/` cannot be mapped to Substack's CMS without proxying.)
5. **Brand-control upside is real.** A custom-domain URL `essays.frqncy.network/p/reading-list-network-states` reads as FRQNCY-native in a way that `frqncy.substack.com/p/reading-list-network-states` does not. For an editorial-standards-forward brand, this matters more than for a typical Substack.

### Trade-off ledger (honest)

| Dimension | Stay on `frqncy.substack.com` | Move to `essays.frqncy.network` |
|---|---|---|
| Cost | $0 | $50 one-time |
| Brand control | Substack-branded URL; OK | FRQNCY-branded; better |
| SEO at relaunch | No URL change; no redirect cost | URL change; modest temporary cost |
| SEO long-term | Permanent third-party subdomain | Permanent first-party subdomain; better |
| RSS continuity | Stable | Substack auto-redirects; stable |
| Email deliverability | Substack handles it | Substack still handles it (custom domain affects URLs only, not sending domain) |
| Reversibility | n/a | Reversible with another DNS edit |
| Decision urgency | None | Defer until after Issue 4 — by then the URL pattern is set and the move is one DNS edit + Substack admin toggle |

### Verdict

Ship the relaunch on `frqncy.substack.com`. Re-evaluate after Issue 4. If Issue 1-4 have shipped on schedule and there is real reader signal, pay the $50, point `essays.frqncy.network` at the publication, let Substack redirect the old URLs. If the publication stalls or the issue-cadence breaks, don't move — a custom-domain ghost-publication looks worse than a Substack-subdomain ghost-publication, because it implies FRQNCY committed where it didn't.

### E1 · Newsletter backend wiring — Substack vs. Klaviyo

`VISIBILITY-PLAN.md` Days 1-30 calls for "Newsletter backend wired (Klaviyo or Substack)." With the Substack relaunch live, the answer is: **Substack is the newsletter backend.** Reasons:

- One subscriber list, not two. Two newsletter providers means two places to forget to send the welcome email, two places to track subscriber count, two places to deduplicate.
- Substack handles email deliverability, RSS, web archive, and the publication-page UX in one stack. Klaviyo would handle email-only and leave the web archive as a custom build.
- Klaviyo's strength (segmentation, automation, e-commerce trigger logic) is for a different stage. FRQNCY's revenue surface is the Fund and Membership, not e-commerce drips. Don't pay for capability that doesn't apply yet.
- **Cost comparison:** Substack free; Klaviyo $20-150/mo depending on list size. The $50 custom-domain fee, if paid, is one-time. There is no scenario where Klaviyo is cheaper for FRQNCY's current shape.

**Implementation:** the `/newsletter/` form on `frqncy.network` posts directly to Substack's subscribe endpoint. Substack accepts a POST to `https://frqncy.substack.com/api/v1/free?email=<address>` (or its current 2026 equivalent — Orlando should verify with Substack's API docs before wiring; the endpoint shape has changed before). The form remains FRQNCY-styled and FRQNCY-hosted; the subscriber record lives in Substack.

Fallback if the API endpoint is fragile: redirect the form submit to `https://frqncy.substack.com/subscribe?email=<address>&utm_source=frqncy_network` — preserves the integration without depending on undocumented endpoints.

### E2 · Cross-publishing essays — FRQNCY-first, Substack-second

The Phase 5.8 reference essays ship at `frqncy.network/essays/<slug>/` first. The Substack version follows, 48-72 hours later, as a *commentary-on-the-essay* — not the same body of text. Two reasons:

1. **Canonical SEO.** Google needs one canonical URL per piece of content. The essay on `frqncy.network` is the canonical reference; the Substack version is the *author's reflection on having published it.* Substack's version includes a `rel="canonical"` pointer to the frqncy.network URL (Substack supports this via the post editor's SEO settings).
2. **Two different reading occasions.** The on-site essay is the reference document the reader arrives at via Google or via a citation. The Substack post is the email-inbox arrival that frames *why* the essay was written, what surprised the author writing it, and where to go next. Different jobs, different drafts.

For the bi-weekly *Notes from the graph* pieces (the shorter cadence), Substack is the primary surface — these aren't reference documents, they're publication-tier writing. They may later be cross-posted to the FRQNCY blog if a `/notes/` route ships, but the source-of-truth is Substack.

## F · Editorial cadence

**Bi-weekly publication. Two surfaces, two cadences.**

- **Long-form essays** — quarterly, per the Phase 5.8 calendar (`runs/2026-05-13-phase-5.8-publication-brief.md`). 5 essays/year. Each lives canonically at `frqncy.network/essays/<slug>/` and gets a 1500-2500 word author's-reflection cross-post on Substack within 72 hours.
- ***Notes from the graph*** — bi-weekly (~26/year). 800-1500 words each. Substack-primary. Three recurring formats:
  - **Topic spotlight** — 3-5 picks from one topic page with the rationale FRQNCY uses (per `EDITORIAL-STANDARDS.md` §4 pick provenance). Roughly every other issue.
  - **Editorial decision in the open** — a real editorial call we made or are weighing (a pick retired, a partnership offered and declined, a topic-page restructured), with the reasoning. Roughly every fourth issue.
  - **Field note** — a shorter piece working out an argument the topic graph implies but no single topic page makes explicit (e.g., "Why FRQNCY treats Auroville and Praxis as the same kind of thing").

### Issue type rhythm (quarterly cycle)

| Week | Type | Surface-first |
|---|---|---|
| 1 | Notes — topic spotlight | Substack |
| 3 | Notes — editorial decision OR field note | Substack |
| 5 | Notes — topic spotlight | Substack |
| 7 | Notes — editorial decision OR field note | Substack |
| 9 | **Reference essay (quarterly)** | frqncy.network (then Substack 48-72h later) |
| 11 | Notes — topic spotlight | Substack |
| 13 | Notes — editorial decision OR field note | Substack |

≈14 issues per quarter / 56 per year minimum (if cadence holds). Quarterly review of cadence — pause threshold is set at "no issue shipped in 14 days," at which point the publication ships an explicit "we're pausing" note. Honesty in cadence is part of the editorial standard; ghosting subscribers without notice violates it.

### What each issue contains (structural template)

- **Subject line** — 50-65 chars. Editorial, declarative, no question marks unless the question is the whole post. No emoji except `✦` (the FRQNCY pick badge) reserved for topic-spotlight issues.
- **Preview text** — 120-140 chars. Substack reads this from the first line of the post; write it intentionally.
- **Top frame** — 2-3 sentences locating the issue in the editorial argument. Who FRQNCY is, what this issue is, why now.
- **Body** — the actual piece. 800-1500 words for *Notes*, 1500-2500 for the essay cross-post.
- **Picks block** (for topic-spotlight issues) — 3-5 picks with rationale per `EDITORIAL-STANDARDS.md` §4.
- **Footer** — three links: (1) the topic page(s) the issue draws from; (2) the editorial standards page; (3) the Telegram channel (post-Day 31 only). Author byline links to `/people/orlando/`.
