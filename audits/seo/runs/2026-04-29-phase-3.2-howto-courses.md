## Why this matters

`HowTo` schema unlocks Google's step-by-step rich results — a card with the course name, total time, and ordered steps appears in search. Pairs naturally with the existing `Course` schema (Phase from earlier today): the same page can carry both, and Google picks the appropriate display format per query intent. Especially valuable for:

- Voice search ("how do I start a meditation practice?")
- Visual SERP ("meditation 101 steps")
- AI engine grounding (structured step-by-step content is highly citable)

## What was NOT done

- `crypto-fundamentals`, `quantum-grammar`, `quantum-reality`, `conscious-living-foundations` — these are conceptual, not step-by-step practice courses. HowTo would be schema-spam there. Course schema (already shipped) is sufficient.
