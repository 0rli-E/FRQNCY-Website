## Baseline 2026-04-29 — key findings

### 1. No direct mentions of `frqncy.network` in public web search

WebSearch run today returned zero results pointing at frqncy.network as the network-state/topic-graph FRQNCY. The site exists, is well-built (757 pages, comprehensive schema, llms.txt, ai.txt) but hasn't surfaced organically yet. This is the baseline number to beat.

### 2. Five FRQNCY brand collisions confirmed

The name "FRQNCY" is contested. Confirmed entities:

- **FRQNCY Media** (frqncy.media) — Atlanta podcast/documentary studio, Michelle Khouri, founded 2018. **Highest competing organic search presence.**
- **FRQNCY Media Group / FMG** (fmgnetworks.com) — conscious-media network, Jody Colvard, 2004
- **FRQNCY** (frqncy.com) — separate entity
- **FRQNCY Performance** — fitness brand
- **FRQNCY Recording Studios** — Aaron Bucktawor

**Strategic implication:** every Phase 5 outreach (press, podcasts, partners) must qualify the brand as "FRQNCY Network" or "frqncy.network" or "FRQNCY topic graph" — never just "FRQNCY". The Knowledge Graph entity briefs (Phase 4.5) already encode this disambiguation in the Wikidata description.

### 3. Twitter handle reality check

The homepage `Organization` schema and the new `/people/orlando/` Person schema both reference `@frqncy_network` as a `sameAs` URL. Search confirms Orlando's actual public handle is `@0xOrli` (display name "Orlando.FRQNCY"). The `@frqncy_network` handle either doesn't yet exist or isn't being used.

**Action item:** Orlando picks one of:
1. Register `@frqncy_network` as a clean institutional handle (recommended — keeps Orlando's personal voice separate from the network's institutional voice).
2. Update the schema to use `@0xOrli` if consolidating.

Until decided, the schema has a soft inaccuracy. Low priority but worth fixing within the week.

### 4. Orlando's existing surface

`@0xOrli` on X exists with the display name "Orlando.FRQNCY" — meaning Orlando has been quietly operating under the FRQNCY brand on a personal handle. This is discoverable evidence supporting:
- Wikidata Person entity creation (sameAs to @0xOrli)
- The /people/orlando/ profile (which currently links to @frqncy_network — should be updated or both kept)

## Why this matters

- **No baseline = no measurement.** Without this scan, we can't tell in 90 days whether the SEO program is actually moving the needle. Now we can: re-run the same searches at +30/+60/+90 days and count.
- **Brand collision is a real constraint.** Without acknowledging it, every outreach risks being mistaken for a different FRQNCY. The MENTION-MONITORING.md doc bakes the disambiguation strategy in.
- **Schema accuracy.** Caught a real soft-inaccuracy in the homepage Organization schema (claims a Twitter handle that may not be live). Phase 5.3 sameAs matrix needs to verify this.
