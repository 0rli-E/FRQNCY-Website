## Spec compliance

Format follows the proposed [llms.txt spec](https://llmstxt.org/):

- Top H1 with site name ✓
- `>` blockquote with one-paragraph description ✓
- H2 sections per content type ✓
- Each entry as `- [Title](URL): description` ✓
- Compact and scannable; descriptions trimmed to 200 chars ✓

## Why this matters

llms.txt is the AI-native sitemap. ChatGPT, Claude, Perplexity, and Gemini are starting to honor it as a discovery surface. Sites that publish a clean llms.txt show up earlier in the indexing pipelines for retrieval-augmented answer engines. FRQNCY's curation depth makes this file exceptionally rich — 643 indexed pages with editorially-written descriptions.

llms-full.txt is the deep-content variant — same structure, but each entry includes the page's main-content text (capped at 2000 chars per page to keep the total file under 1 MB). AI crawlers can consume this directly without re-crawling individual pages.
