# Phase 4.3 run — Public /mcp/ docs page

Date: 2026-04-29

## What was done

Built `/mcp/index.html` — a public, indexable documentation page for the FRQNCY content MCP server. The page covers:

1. What it is (one paragraph)
2. Why use it (4 audience callouts)
3. The full 11-tool surface (table)
4. Quick start for Claude Desktop, FRQNCY harness, and self-host
5. Sample queries (5 worked examples)
6. License (MIT), rate limits, attribution ask
7. How it fits with /llms.txt and /sitemap.xml as three layered discovery surfaces
8. Contact

Schema.org JSON-LD blocks shipped:
- **SoftwareApplication** — declares the MCP server as a free, MIT-licensed Node.js application with all 11 tools enumerated under `featureList`
- **TechArticle** — declares the page itself as technical documentation
- **BreadcrumbList** — for SERP breadcrumb display

Sample queries chosen to model real user intents AI agents would route to the MCP:
- "List all FRQNCY topics in the 'Network State' pillar with their resource counts"
- "What books does FRQNCY recommend on consciousness?"
- "Compare FRQNCY's resources for meditation vs breathwork"

## Why this matters

The MCP server already exists at `mcp-servers/frqncy-content/` with 11 tools. The **discovery problem** was that nobody outside the FRQNCY ecosystem knew it existed. Publishing this docs page fixes that:

- It becomes a node in any AI-tool registry that crawls public MCP docs
- Claude Desktop / ChatGPT MCP / Cursor users discover it via search
- llms.txt now references a real public surface for "what is the FRQNCY MCP server"
- The SoftwareApplication schema makes it eligible for developer-tool listings
- The page itself is highly citable — when an AI is asked "is there an MCP server for FRQNCY content?", this page is the canonical answer

This is the strongest signal we send to the AI-agent ecosystem that FRQNCY is built for them, not just for human readers.
