## Critical findings

### 1. Soft schema inaccuracy confirmed

The homepage `Organization.sameAs` asserts `https://twitter.com/frqncy_network`, but WebSearch can't find that handle. It is either unclaimed or dormant. The `/people/orlando/` Person schema's `sameAs` array contains only the canonical self-URL — which is malformed; sameAs should reference EXTERNAL surfaces, not the page's own URL.

Both inaccuracies persist until the handle decision lands and the schema gets patched. See the handle-decision brief.

### 2. Brand-collision landscape expanded (10 confirmed entities, up from 5)

The Phase 5.10 baseline tracked 5 colliding FRQNCY entities. This audit surfaced 5 more:

- **@FRQNCY_live** — Pickathon livestreaming platform (Oregon)
- **@FRQNCYSA** — clothing / lifestyle brand
- **@FRQNCY_shop** — separate retail brand
- **@frqncyofficial** — fourth lifestyle/retail account
- **"FRQNCY - Topic" on YouTube** (UCg7qlHd579xMoFIRnUXQ2Ag) — auto-generated channel for a music artist named FRQNCY
- (Plus the existing 5: FRQNCY Media, FRQNCY Media Group, FRQNCY (frqncy.com), FRQNCY Performance, FRQNCY Recording Studios)

The competitive density on the bare term "FRQNCY" is now severe. Every brand surface should qualify with "Network" or "topic graph for consciousness" in the bio. The recommended handles in SAMEAS-MATRIX all use `frqncy_network` or `frqncy.network` (with the qualifier) — handles without the qualifier are mostly already claimed.

### 3. Podcast platform collision is critical

The Spotify and Apple Podcasts entries for "FRQNCY" are both **already taken by FMG's actual podcast (hosted by Jody Colvard)**. Publishing The FRQNCY Podcast on those platforms under just the name "FRQNCY" will trigger search-result fusion with FMG's existing show.

**Recommendation:** publish as **"The FRQNCY Network Podcast"** (or "FRQNCY: The Topic Graph") to give Spotify a distinct title to index. Detailed in SAMEAS-MATRIX §8 / §9.

### 4. Substack is positioned wrong for the current strategy

`frqncy.substack.com` is verified-live and owned by Orlando — but its last public post (per WebSearch) is a December 2023 "Daily Crypto Update". For the SAMEAS sub-strategy to compound, this publication should either:

a) **Re-position as the FRQNCY Network publication** (recommended) — re-name, re-brand, re-target to topic-graph long-form essays.

b) **Be retired or handed off** — and a fresh Substack launched under the FRQNCY Network identity.

Option (a) preserves the URL and any existing subscriber list. Detailed in SAMEAS-MATRIX §10.
