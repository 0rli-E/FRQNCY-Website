## Submission 3 — Smithery.ai

**URL:** https://smithery.ai/

**Format:** GitHub-PR-driven registry. Smithery auto-pulls metadata from `smithery.yaml` if present in the repo, otherwise from package.json + README.

**Action:**

1. Add `smithery.yaml` to the MCP server directory (`mcp-servers/frqncy-content/smithery.yaml`):

```yaml
startCommand:
  type: stdio
  configSchema:
    type: object
    properties:
      FRQNCY_CONTENT_DIR:
        type: string
        description: "Optional path to FRQNCY content (search.json + resources.json). Defaults to bundled."
  commandFunction: |
    (config) => ({
      command: 'node',
      args: ['index.js'],
      env: config.FRQNCY_CONTENT_DIR ? { FRQNCY_CONTENT_DIR: config.FRQNCY_CONTENT_DIR } : {}
    })
```

2. Open https://smithery.ai/server/new (or current equivalent), paste the GitHub URL: `https://github.com/0rli-E/frqncy-network/tree/main/mcp-servers/frqncy-content`

3. Smithery auto-pulls README, package.json, and smithery.yaml. Verify the auto-generated description and categories.

**Expected outcome:** indexed within 1-2 days; appears in client-side picker for users who use Smithery's MCP client. Smithery also generates a config-form UI that simplifies install for non-technical users.
