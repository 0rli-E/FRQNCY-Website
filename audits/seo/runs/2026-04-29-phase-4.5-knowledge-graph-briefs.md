# Phase 4.5 run — Knowledge Graph entity briefs (Wikidata-ready)

Date: 2026-04-29

## What this is

Wikidata-ready submission packages for the four FRQNCY-adjacent entities that should exist in the knowledge graph. Each brief contains everything Orlando needs to paste into <https://www.wikidata.org/wiki/Special:NewItem>.

Wikidata is more permissive than Wikipedia on notability — any subject discussed in even a single secondary source can have an entity. So even entities that won't pass Wikipedia's bar today can be in Wikidata immediately. Wikidata then becomes the structured-data substrate that feeds Google Knowledge Graph.

After each entity is created and assigned a Q-number, the FRQNCY homepage `Organization` JSON-LD's `identifier` and `sameAs` arrays should be updated to reference them.

## Why this matters

The Knowledge Graph is the spine of:

- **Google "knowledge panels"** — the right-side card on a SERP showing logo, founder, founded date, official URL.
- **AI engine grounding** — ChatGPT, Claude, Perplexity all retrieve knowledge graph entries when answering "what is FRQNCY".
- **Cross-platform entity resolution** — a Wikidata Q-number is the canonical pointer that lets every other platform's entity references resolve to the same thing.

Even one Wikidata entry per FRQNCY-adjacent entity puts the foundation in place. Wikipedia articles can follow once notability accumulates; until then, Wikidata is the win we can take immediately.

## Submission process for Orlando

For each of the four entities:

1. Sign in at https://www.wikidata.org with the FRQNCY Wikimedia account (create one with hello@frqncy.network if needed).
2. Open https://www.wikidata.org/wiki/Special:NewItem.
3. Paste the label and description.
4. Add statements one at a time using the "edit" panel after the entity is created. Wikidata's editor surfaces property suggestions as you type.
5. Add references for any statement that's likely to be challenged (instance of, founded by, instance of human, etc.).
6. Capture the Q-number from the URL after save.
7. Submit a post-creation update to the FRQNCY repo: edit the relevant JSON-LD blocks to add `identifier: PropertyValue` and `sameAs` URL.

Estimated time: 30-60 minutes per entity, mostly choosing the right Wikidata properties from autocomplete.
