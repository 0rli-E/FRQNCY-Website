### Step 3 — Wire IndexNow

The keyfile at `/cb4283bd575faacde2dd9ce4de81db74.txt` is already on disk and will be served once the site deploys. Ownership verification works automatically when IndexNow servers fetch it.

To actually USE IndexNow (push notifications when content changes), add a deploy hook. Quick path: a Cloudflare Pages Function that runs on deploy and POSTs the changed-URL list:

```javascript
// functions/_indexnow-onbuild.js (commented-out by default; enable after testing)
const KEY = "cb4283bd575faacde2dd9ce4de81db74";
const HOST = "frqncy.network";

export async function onRequest(context) {
  // List of changed URLs since last deploy — populate from git diff or a manifest file
  const urlList = [
    "https://frqncy.network/",
    "https://frqncy.network/explore.html",
    // ... add changed URLs
  ];
  const body = { host: HOST, key: KEY, keyLocation: `https://${HOST}/${KEY}.txt`, urlList };
  const r = await fetch("https://api.indexnow.org/indexnow", {
    method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body)
  });
  return new Response(`IndexNow status: ${r.status}`);
}
```

Test the fetch manually first:
```bash
curl -X POST https://api.indexnow.org/indexnow -H "Content-Type: application/json" -d '{"host":"frqncy.network","key":"cb4283bd575faacde2dd9ce4de81db74","keyLocation":"https://frqncy.network/cb4283bd575faacde2dd9ce4de81db74.txt","urlList":["https://frqncy.network/"]}'
```

Should return HTTP 200 once the keyfile is reachable.
