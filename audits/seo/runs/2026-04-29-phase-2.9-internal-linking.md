## What was injected

Each item page now displays an "Anchored to" block before the footer, listing the topics that anchor it:

```html
<section class="anchored-topics">
  <div>Anchored to</div>
  <div><a href="../../v2/<topic-1>/">Topic 1</a>, <a href="../../v2/<topic-2>/">Topic 2</a>, ...</div>
</section>
```

## Why this matters

This closes the cluster loop. Topic pages already list their resources (forward links). Now resource pages link back to their topics (reverse links). Three benefits:

1. **Topical authority signal:** Google reads bidirectional cluster linking as a strong topical-coherence signal. A book about meditation linking back to /v2/meditation/ and /v2/wellbeing/ tells Google the cluster is real.
2. **Reader navigation:** a reader on a book page now has a one-click path back to the broader topic context. Conversion to deeper engagement.
3. **AI grounding:** when an AI engine sees `/books/blink/` in a citation, the linked topics tell it which subjects this book is editorial-relevant to. Grounds future answers better.
