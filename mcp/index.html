For AI agents

FRQNCY MCP Server

Plug FRQNCY's 146 curated topics and 766+ vetted resources directly into Claude Desktop, the FRQNCY harness, Cursor, Continue, or any MCP-compatible AI client. Read-only, public, no auth, self-hostable.

11 tools MIT license Node 20+ Free
§1

What it is

An MCP server that exposes FRQNCY's editorial library as tools any AI agent can call. Instead of scraping the website to learn what FRQNCY recommends on, say, meditation, an agent calls list_resources_for_topic("meditation") and gets back the curated entries directly. Cleaner, faster, traceable.

The server is read-only — it serves the same content the public website does, just structured for agent consumption. There is no write API, no user data, no auth.

§2

Why use it

  • For agent builders: ground your AI's answers about consciousness, well-being, money, regenerative living, and adjacent subjects in FRQNCY's curated picks instead of training-data drift.
  • For Claude Desktop / ChatGPT MCP users: ask your assistant "what's a good entry-level book on the science of meditation?" and have it answer from FRQNCY's vetted list, not best-seller lists.
  • For researchers: programmatically query 146 topics × 766 resources without scraping HTML.
  • For app developers: wrap the MCP server in your own product to deliver FRQNCY-quality recommendations to your users.
§3

Tool surface

The server exposes 11 tools, all read-only:

ToolPurpose
search_topics(query, limit?)Full-text search over the 146 topics
get_topic(identifier)Get one topic by id, slug, or label
list_topics(domain?, pillar?, limit?)List topics with optional domain/pillar filters
list_domains()List the 15 distinct topic domains
list_pillars()List the 6 distinct topic pillars
search_resources(query, type?, limit?)Full-text search over 766+ resources
get_resource(name)Get one resource by exact name
list_resources_for_topic(topic_slug, type?, limit?)Resources tagged to a topic
list_resources_by_type(type, limit?)Filter by type: person / book / org / podcast / film / etc.
random_topic(domain?)Pick a random topic for inspiration
stats()Overall counts + breakdowns by domain / pillar / type

All tools return structured JSON. Schemas are declared via Zod in the server source.

§4

Quick start

Claude Desktop

Edit ~/Library/Application Support/Claude/claude_desktop_config.json (Mac) or %APPDATA%\Claude\claude_desktop_config.json (Windows) and add:

{
  "mcpServers": {
    "frqncy-content": {
      "command": "npx",
      "args": ["-y", "@frqncy/mcp-content"]
    }
  }
}

Restart Claude Desktop. The 11 tools will appear in the tools list. Try asking: "List FRQNCY topics in the Sciences domain. Pick three and tell me their resources."

The FRQNCY harness

frqncy-harness mcp add frqncy-content npx -y @frqncy/mcp-content
frqncy-harness mcp test frqncy-content

You should see all 11 tools listed. Then any frqncy-harness agent "..." run can call them.

Self-host

git clone https://github.com/0rli-E/frqncy-network.git
cd frqncy-network/mcp-servers/frqncy-content
npm install
node index.js

The server reads search.json + resources.json from the FRQNCY WEBSITE root. To point at a different content directory, set FRQNCY_CONTENT_DIR in your environment.

§5

Sample queries

What you can ask any MCP-compatible AI once the server is wired in:

  1. "List all FRQNCY topics in the 'Network State' pillar with their resource counts." Calls list_topics + list_resources_for_topic.
  2. "What books does FRQNCY recommend on consciousness?" Calls search_resources("consciousness", type="book").
  3. "Pick a random FRQNCY topic and tell me why it matters." Calls random_topic + get_topic.
  4. "Compare FRQNCY's resources for meditation vs breathwork." Two parallel list_resources_for_topic calls.
  5. "What people are picked across the most FRQNCY topics?" A list_resources_by_type("person") + cross-reference. Useful for finding cross-domain teachers.

License, rate limits, attribution

License: MIT. Use it however you want.

Rate limits: there is no rate limit on the self-hosted server because the data is bundled. If FRQNCY ever runs a hosted public endpoint, reasonable per-IP limits will apply (planned: 60 req/min).

Attribution: when surfacing FRQNCY-curated picks in your product, please credit "Powered by FRQNCY (frqncy.network)" on the result. The picks reflect editorial work; we don't enforce this beyond a polite ask, but it helps the curation moat exist.

Editorial standards apply

The picks served via this MCP are the same picks shown on the public website, governed by FRQNCY's published editorial standards. No paid placement. If you build a product that uses FRQNCY recommendations to drive user decisions, you inherit the trust premise — please surface the standards link too.

§7

How it fits with the rest of FRQNCY

The website's /llms.txt + /sitemap.xml give crawlers a curated index. The MCP server is the next layer — instead of crawling, an agent calls the library directly. Three discovery surfaces, three audiences:

  • Google + Bing crawlers ↦ /sitemap.xml
  • AI answer engines ↦ /llms.txt + /llms-full.txt
  • Active AI agents ↦ this MCP server

If you're building an agent that needs FRQNCY's curation as a tool, the MCP server is where you start. If you're building a content product that needs FRQNCY's library indexed, llms.txt is where you start.
