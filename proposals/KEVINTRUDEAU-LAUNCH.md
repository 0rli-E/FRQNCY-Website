## 0. Compliance spine — read before every post

Non-negotiable. This channel touches health and money, so the bar is FTC/FDA-safe or it does not ship.

- **No cure claims. No guarantees.** Never "this cures," "this works," "you will lose X," "you will make X." Always "he argues," "his view is," "explores the idea that," "supports," "promotes," "may support."
- **Health = supports/promotes only.** Frame every body-topic as an experiment, not a prescription. Never tell anyone to stop a treatment, skip a doctor, or replace medicine. Add: "Not medical advice. Talk to a professional you trust."
- **Money = education, not advice.** Never "get out of debt guaranteed," "free money you're owed." Reframe as principles and mindset. Add: "Not financial advice."
- **Own words only.** Write from the summary with the transcript closed. No sentence echoes. One or two short attributed quotes max.
- **Every visual is ours or licensed.** No Trudeau footage, no book scans, no infomercial clips. Recreate charts in Canva/CapCut from underlying data, labeled "based on ideas discussed by Kevin Trudeau."
- **The disclosure rides on every piece** — bio, pinned comment, and description. Same wording each time (Section 2).
- **The FTC history is not hidden, not defended.** If a comment raises it, respond once, factually, and pivot to the teachings: *"Kevin Trudeau has a documented legal and FTC history — that's public record. This channel curates his ideas, not his court record. Take what's useful, leave the rest, think for yourself."* Do not argue. Do not litigate. Do not delete honest questions.

Four checks before anything posts: (1) written from the summary, no echoes; (2) quotes ≤ 2 lines, credited; (3) every visual ours/licensed; (4) reads as *our* teaching about his idea, framed as his view, no cure/income promise. All four yes → ship.

- **Weeks 1–2:** 1 post per platform per day. Same core piece reformatted 5 ways. That's 7 pieces/week carrying all five platforms.
- **Weeks 3–4:** 1/day/platform, but stop cloning the same piece across all five on the same day — stagger so each platform gets its own daily piece from the batch of 12.
- **Week 5+:** scale to 2/day on YouTube Shorts + TikTok (the discovery engines), hold 1/day on IG/FB/X. Add the weekly long-form on YouTube.
- **The rule:** cadence scales only when the batch and the automation hold. Never post faster than the compliance check can keep up.

### How one batch feeds everything

The weekly batch is **12 own-words pieces** (Section 4). Each piece produces:

1. A **9:16 short** (voice-clone narration over ESA/NASA + Canva visuals) → YouTube Shorts, IG Reels, TikTok, FB Reels.
2. An **X post** (the hook + 3–4 talking points as a short thread, native video attached).
3. Once a week, **three pieces on one pillar** stitch into a **long-form YouTube video** ("Kevin Trudeau's ideas on money, in my own words — 3 concepts").

12 pieces = ~2.5 weeks of daily posting at 1/day/platform, or ~1 week once scaled. Batch every other weekend and you are always a fortnight ahead.

## 6. Make it permanent — the automation recommendation

The channel stays alive because a recurring task keeps producing the batch and a human keeps approving it. Two moving parts: a scheduled draft, and a hard approval gate.

**Recommended setup:**

1. **Recurring weekly content-draft task.** A scheduled task (the `scheduled-tasks` / `schedule` capability) runs every **Sunday 08:00**: Claude reads this file + `OWN-WORDS-PIPELINE.md` + `FRQNCY-VOICE-PLAYBOOK.md`, drafts the next 12 pieces rotating through Pillars A–E, self-runs the four compliance checks, and drops the draft into a review file (e.g. `engine/kt-batch-YYYY-WW.md`). It never posts. It only drafts.

2. **The approval gate (non-negotiable).** Nothing schedules until Orlando marks the batch approved. The task's output is a *draft*, and the compliance spine (Section 0) is the checklist. Because this touches health and money, human sign-off stays in the loop permanently — that is the feature, not the friction.

3. **A rotating source queue.** Keep a running list in `engine/kt-source-queue.md` of Trudeau themes not yet covered, so the weekly draft never repeats and never runs dry. Seed it from the five pillars; each covered concept gets checked off.

4. **A monthly voice/compliance audit.** Once a month, run the batch through `brand-voice:enforce-voice` against the playbook and re-read Section 0. Catches drift before it ships.

To wire the recurring task today: create a scheduled weekly task pointed at this file with the instruction *"Draft the next KevinTrudeau.frqncy batch of 12 per KEVINTRUDEAU-LAUNCH.md Sections 3–4, run the Section 0 checks, write to engine/kt-batch-<date>.md, do not post."* Then the only standing human job is the weekly approve-and-schedule pass.
