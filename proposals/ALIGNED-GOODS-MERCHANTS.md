# Aligned Goods — Merchant Tracking Sheet

Per-merchant ledger for the Aligned Goods index. Tracks which brands FRQNCY points at, where they sit on the four-tier relationship ladder, who owns the outreach, and what each one contributes. Auto-generated initial state — maintained by hand thereafter as deals close.

**Last refreshed:** 2026-06-08

See `proposals/PARTNER-STRATEGY.md` for the four-tier ladder, outreach workflow, and the cold-email template. See `proposals/EDITORIAL-STANDARDS.md` for the picking rubric.

## How to use this sheet

Update one row per merchant per move:

1. **Researched** → fill the Notes column with the affiliate URL or contact email.
2. **Reached out** → set Owner to whoever sent the email; set Last touched to today; set Status to `Affiliate · enrolling` or `Discovery call scheduled`.
3. **Closed** → flip Status to `Affiliate · LIVE` / `Contributor` / `Partner`; update the live URL in `aligned-goods.json`; bump `sw.js` VERSION; push.
4. **Failed** → set Status to `Declined` or `No fit` with a one-line reason in Notes. Re-attempt cadence: 6 months.

## Status legend

- **None** — no relationship today, picked on merit alone (Tier 0)
- **Affiliate · pending** — placeholder `?ref=frqncy` URL in place; awaiting program enrollment (Tier 1)
- **Affiliate · enrolling** — application submitted, awaiting approval (Tier 1)
- **Affiliate · LIVE** — tracked URL is live and earning (Tier 1)
- **Discovery call scheduled** — Tier 2/3 conversation in progress
- **Contributor** — direct contribution to the FRQNCY Fund or a Sanctuary (Tier 2)
- **Partner** — revenue-share or co-marketing agreement live (Tier 3)
- **Declined / No fit** — outreach attempted, not currently viable. Re-attempt in 6 months.
