# IG 3-Channel Plan — spirituality.frqncy · books.frqncy · money.frqncy

> The operating plan for running three Instagram channels at 1 reel/day each, consistently, then scaling. Built on what's already proven: the PD library (FREE-CONTENT-LIBRARY.md), the 7 banked scripts (engine/script-bank-batch1.md, batch2), the render pipeline (engine/render.sh, karaoke captions locked), and the voice playbook (FRQNCY-VOICE-PLAYBOOK.md).
>
> Created: 2026-07-22. Owner: Orlando. Status: ready to execute — days 1–3 are fully banked.

## The system in one paragraph

Three channels, one machine. Every reel teaches one idea from the public-domain library or the own-words pipeline, in Orlando's cloned voice, over dense ESA/NASA footage with blue-on-white karaoke captions. Every reel ends the same way: a comment keyword (CREATE / READ / RICH). CreatorFlow turns the comment into a DM with a link to the matching subsite page on frqncy.network, where the free book or audio lives. The free layer builds the email list; the email list carries the affiliate offers; the revenue funds FRQNCY. The reel is the doorway. The teaching lives on the site.

**Voice rules apply to every caption, hook, and DM** (see FRQNCY-VOICE-PLAYBOOK.md): present tense, short declaratives, triads, remembrance not instruction, practices as experiments, abundance frame, no banished terms (no "unlock," "level up," "vibes," "high vibe," "do the work," "game changer"), no ranking people, British English in prose.

# 5. Scaling ladder

**Rung 0 → 1 (now): 1/day per channel.** The only goal is 14 consecutive days with zero missed slots and the 3-day buffer intact. Nothing else counts as stable.

**Rung 1 → 2: 2/day on one channel.** Trigger: 14 clean days AND the weekly review shows one channel clearly ahead on keyword comments per reel. Rules: the second daily slot goes to that channel only; it's always a light format (One-Line Experiment / The One Line / Ledger Experiment — 25–40s, ~10 minutes of assembly); it gets the opposite time-of-day slot from the channel's main post. Batch sessions grow to ~2.5h, still two per week. If the buffer ever drops below 3 days, drop back to 1/day without ceremony — the ladder goes both directions.

**Rung 2 → 3: 2/day on all three.** Trigger: 14 clean days at rung 2. At 42 reels/week, add a third weekly batch session or move assembly fully to the agent-run engine with Orlando approving finished renders in one sitting.

**Rung 3 → 4: secondary platforms via Postiz cross-posting.** Trigger: rung 2 stable and the funnel converting (DM link-taps → email signups measurable). Same video files, per-platform tweaks:

# 6. Consistency safeguards

**The minimum viable post.** If a day breaks — travel, render failure, voice-gen down — the slot still fills. The MVP is: one ESA still (dense crop), one PD line as a static text card in the locked caption style, the channel keyword CTA in the caption. Ten minutes, no voiceover, no render pipeline. Every channel keeps a folder of 3 pre-made MVP cards at all times, so the true worst case is "open Postiz, schedule a card." A quiet card in voice beats a missed day, and beats a rushed off-voice reel.

**The buffer.** Three days scheduled ahead per channel, always — that's 9 reels in the Postiz queue as the floor. The batch session doesn't run on a calendar day; it runs on a trigger: when any channel's queue shows 3 days remaining, the next session is booked within 48 hours. Two sessions a week maintains this at 1/day cadence with margin.

**The Metricool weekly review — 15 minutes, Mondays, timeboxed.**

1. *Minutes 0–5 — the funnel number first.* Keyword comments per reel, DM link-taps, email signups per channel. This is the metric that matters; views are weather.
2. *Minutes 5–10 — retention and saves per format.* Each of the nine recurring formats gets a running average. A format (never a person, never an author) that sits last in its channel for six consecutive reels gets killed and replaced with a variant.
3. *Minutes 10–15 — one kill, one double, one experiment.* Kill or bench the weakest format if it's at strike six. Double the format with the highest keyword-comment rate (it takes the next open calendar slot twice next week). Name one experiment for the week — a posting-time shift, a hook style, a new source shelf — and write it as one line at the top of next week's calendar. Then stop. The review is fifteen minutes because a review that takes an hour stops happening.

**What never changes under pressure:** the voice rules, the edition rules (1937 Hill, 1926 Holmes, 1975 ACIM, 1946 Yogananda, old translations), the credit lines (ESA/Webb, NASA & CSA; own-words creator credits; non-affiliation disclaimers), the never-someone-else's-audiobook rule, and the money/health framing (supports and promotes — never cures, never guarantees, never calls).
