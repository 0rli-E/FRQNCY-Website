## 2. Research papers — yes, and here's the machine

- **Facts and findings are not copyrightable.** Discussing/summarising ANY paper — including paywalled — is legal, monetised or not. The only limit: don't closely paraphrase their sentences. Read → close → explain in your own words.
- **CC BY papers** (most PLOS, Frontiers, Nature Comms, Scientific Reports, eLife): quote at length, show figures full-screen, animate them — with attribution. Check licence via Unpaywall/the article page. **PsyArXiv preprints are always CC0/CC BY** — the best-licensed source for meditation/psychedelics content.
- **Paywalled figures:** default to **redrawing the chart from the data in FRQNCY house style** (data is uncopyrightable; looks better anyway). Showing 1–3 original figures while actively discussing them is a solid fair-use posture; publishers enforce against piracy, not commentary channels.
- **The real risk is FTC/FDA, not copyright — and only when money touches health content.** Pure editorial "here's what this RCT found" = protected speech. The moment a video sells/affiliates a product: claims need RCT-level substantiation, in-video disclosure, and never place a study citation next to a product (FDA reads that as drug intended-use). 
- **Script guardrails:** never "proves/cures/prevents." Always: study type, N, vs-placebo result, limitations, "educational, not medical advice." "Doctors don't want you to know" = never (FTC red flag + platform strike magnet).
- Standing format: name paper on screen (title/journal/DOI) → study type + size up front → redrawn chart → own-words findings → limitations → link in description.

## 4. The weekly operating system (~15h/week solo)

Batch by *mode*, never by channel. Two pillars/week → 20–24 assets → every channel fed 2x/week.

| Block | When | Hours | Output |
|---|---|---|---|
| Ideation + outlines | Mon AM | 2 | 2 pillar topics from idea bank, outlined against series templates |
| **Record** | Tue | 3 | 2 × 15–25 min recordings, one setup, back-to-back |
| Fan-out (write) | Wed | 3 | Transcript → 20–24 assets via hook library + caption templates (LLM drafts, human voice pass) |
| Edit + schedule | Thu | 4 | 6–10 clips, template graphics, load Postiz for Mon+Thu publish waves |
| Engagement | Daily | 0.5 cap | Rotate 2–3 channels/day |
| Review | Fri | 1 | Metrics pass; adjust max one format/month |

**Rules that make 10 channels survivable:**
- Every channel gets **one named series format** ("same format, new topic") — new episode = topic swap, ~10–15 min scripting.
- **Hook library**: 5–10 tested fill-in-the-blank hook formulas; first 3 seconds decide 71% of viewers.
- **2x/week per channel is the evidence-backed optimum** — 1–2x/week shows the highest per-video performance; daily posting correlates with decline + burnout. Algorithms punish stopping, not moderate cadence.
- Content-ops schema: Pillars table → Assets table → Channels table (Airtable/Notion — or the FRQNCY context graph itself).

**First hires when revenue allows (~$1,000–1,500/mo total):** short-form editor ($500–1,000/mo, per-clip $25–75 to start) then Filipino VA for scheduling/triage ($400–600/mo, OnlineJobs.ph) → founder time drops to ~8h/week.

**Documented failure modes to avoid:** all-10-bespoke-content (collapse), daily posting (burnout, 90% of creators), burst-then-silence (algorithmic death), hand-crafting every post (marginal cost never hits zero).
